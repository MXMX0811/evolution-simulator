# v6 验证报告

后续补充：[长时演化与创新瓶颈审计](evolution-audit.md)将同一 v6 模型的四个默认世界延长到 T36000，并增加遗传提案追踪、门槛及资源拆分对照、体型实验与双向低丰度引入。本文保留 v6 实现阶段的 T12000 比较及原始验证结果。

记录日期：2026-09-30。v6 的代谢分配、局部资源接触、结构蓝图遗传和群落生活史已经通过实现检查，也产生了可追溯的群落繁衍。**本轮尚未验证稳定生态共存，也未在默认长跑中观察到组织、两侧或辐射体制的自然出现。** 多样性和复杂化仍是待解决的问题。

设置、检查点和实验结果见 [v6 校准数据](benchmarks/v6-calibration.json)。此前的 16 轮环境矩阵保留在 [v5 版本验证说明](https://github.com/MXMX0811/evolution-simulator/blob/cc24ca573b3d975a575e0a8cb621f0804f8dd543/docs/validation.md)，其中旧版测试和审计结果不计入本报告。

## 自动检查

本次完整测试集 **103/103 通过**。检查覆盖遗传来源、潜在结构与实际表达、分类标签不干预生态决策、能量与养分账、保存恢复、代谢投入权衡、身体跨格接触、群落生长和繁殖、形态连接及观察界面。

新增检查包括：共同投入预算不能同时无限增加各条摄食通路；按比例降低投入不能保持免费摄取；身体覆盖多个场格时分摊同一份摄取请求；缺失前置结构使下游蓝图失活而不连带抹除遗传信息；细胞增长与繁殖体释放支付实际材料。检查通过表示这些行为符合当前实现约定，不等于模型已得到现实生态数据验证。

## 默认世界：四种子、两个观察时点

使用 `ORIGIN-042`、`DELTA-103`、`EDEN-221`、`STUDY-004`。每个版本均从四个独立起源体系、每体系 26 个复制者开始，使用默认温度 24°C、光照 1、资源补给 1、海平面 0.57、出生突变率 0.09、环境波动 0.3，并允许科幻结构。每个世界连续运行到 T12000，在 T6000 和 T12000 记录完整指标；这两个时点不是独立重复实验。

基线为提交 `cc24ca573b3d975a575e0a8cb621f0804f8dd543` 的 v5 模型。表中箭头均表示 **v5 → v6**。

| 种子 | 时点 | 个体数 | 现存标签数 | 有效标签数量 |
|---|---:|---:|---:|---:|
| ORIGIN-042 | 6000 | 344 → 1251 | 2 → 4 | 1.749 → 2.299 |
| ORIGIN-042 | 12000 | 860 → 1139 | 8 → 5 | 4.538 → 1.187 |
| DELTA-103 | 6000 | 474 → 1433 | 3 → 6 | 1.358 → 2.093 |
| DELTA-103 | 12000 | 910 → 1698 | 4 → 11 | 1.356 → 3.084 |

有效标签数量为 `exp(Shannon 熵)`：它描述当前丰度是否由少数标签主导。标签是模型中的分群记录，不能直接当作完整生物物种，也不是稳定共存的判据。

八个版本／种子组合均运行到 T12000，没有达到 2200 个体计算上限。**v6 在四个终点中的三个具有更低的有效标签数量。** v6 四个终点分别剩余 2、2、1、1 个初始起源体系；ORIGIN 和 DELTA 的主导起源分别占总个体数的 99.74% 和 96.94%。标签增加与初始起源丢失可以同时发生。

四轮 v5 共记录 41510 次出生，v6 共记录 100325 次出生。T12000 时，v5 当前存活个体的最高世代为 58–61，v6 为 58–96。时步不是世代；同一观察时点也不代表相同的变异供给和演化机会。

| 种子，v6 T12000 | 携带群落结构的现存个体 | 实际拥有多个细胞单元的身体 | 累计群落结构传承出生 |
|---|---:|---:|---:|
| ORIGIN-042 | 23 | 11 | 228 |
| DELTA-103 | 43 | 18 | 123 |
| EDEN-221 | 7 | 1 | 901 |
| STUDY-004 | 37 | 13 | 214 |

携带群落结构的幼体可以仍只有一个细胞单元，因此不能把两列混为一谈。v5 没有实际细胞数量生活史，其四个世界在两个检查点均无现存群落结构携带者；但 DELTA 的 v5 历史档案已有 3 个携带者和 2 次结构传承，不能将旧版描述成“群落从不留下后代”。

群落的扩散也可能退缩。例如 EDEN 在 T7800 有 343 个体，其中 186 个携带群落结构、132 个已形成多细胞身体；到 T12000 只剩 7 个携带者和 1 个多细胞身体。这是短暂扩散后衰退的记录，不是稳定维持的证据。

四个 v6 默认世界到 T12000 均未记录组织、两侧或辐射结构的出现。独立形态组合实验中的复杂身体不能计入自然演化结果。

## 群落生活史：60 次固定克隆实验

使用 ORIGIN 和 DELTA 两个种子，分别在光照 1 的 mixed 和光照 1.6 的 bright 环境中，比较成熟规模 N2–N6 的群落、具有组织输运的群落，以及相同基因和形态参数的单体对照。总计 `2 种子 × 2 环境 × 5 规模 × 3 结构条件 = 60` 次运行，其中群落和组织条件共 40 次。

每个世界独立放入 26 个精确克隆，从一个细胞单元和 17 单位储备开始，均携带光合色素、光能投入基因值为 0.9。突变率和环境波动为 0，采用无性繁殖。成熟规模只通过 `shape[3]` 改变，其余基因相同；单体对照也使用对应的 `shape[3]`。初始材料和能量作为外部输入入账，后续生长与繁殖由个体支付。

所有运行均到达 T1500，均有出生及存活后代，没有容量中止。40 个群落／组织条件全部完成成熟与繁殖，首次成熟分别为 N2 的 T12、N3 的 T24、N4 的 T36、N5 的 T48 和 N6 的 T60。

| 环境 | 结构 | T1500 个体数范围 | 累计出生范围 | 首次出生时点范围 |
|---|---|---:|---:|---:|
| mixed | 单体 | 74–82 | 245–254 | 32–33 |
| mixed | 群落 | 16–59 | 84–184 | 39–78 |
| mixed | 组织 | 12–42 | 56–155 | 42–92 |
| bright | 单体 | 197–217 | 624–748 | 18 |
| bright | 群落 | 159–207 | 549–661 | 21–60 |
| bright | 组织 | 147–211 | 495–619 | 21–60 |

这组结果说明：身体接触多个局部资源格后，所选光合克隆能够支付增长、成熟并释放繁殖体。它检验的是**生活史可行性**。各条件没有放在同一个世界中竞争，不能用于证明群落的选择优势。它也不代表随机初始生命能演化出该基因组合。

每个条件只有两个种子重复。同一种子和环境下，五个单体对照仅改变 `shape[3]`，结果相同，不能把它们当作五个独立随机重复。60 次实验共记录 23400 次出生，细胞分布、首胎、增长和维护账户见实验脚本输出；仓库校准数据保留各轮关键指标。

## 稀有入侵：12 个方向及适用边界

在两个种子、mixed／bright／dim 三种环境中，分别建立光合型或化能型居民，再引入另一策略。光照分别为 1、1.6、0.35，资源补给均为 1；地形、热泉和水深仍具有空间差异。

每次使用 52 个固定基因居民，关闭突变和环境波动，采用无性繁殖。居民运行 1200 时步后，若仍存活且未达容量，加入 8 个独立起源的入侵者，再观察 1200 时步。引入所带能量和材料通过 `injectLife` 入账。初始比例不超过 10% 才标记为稀有；这是一项明确的试验约定，不是普遍生物学阈值。固定建立期也不能保证居民已经平衡。

表中箭头表示入侵者及其后代的数量变化。居民提前灭绝时不执行引入。

| 种子 | 环境 | 光合居民中引入化能型 | 化能居民中引入光合型 |
|---|---|---|---|
| ORIGIN | mixed | 稀有，8 → 7 | 初始占比 53.33%，8 → 64，非稀有 |
| ORIGIN | bright | 稀有，8 → 1 | 初始占比 66.67%，8 → 158，非稀有 |
| ORIGIN | dim | 居民于 T748 灭绝 | 居民于 T669 灭绝 |
| DELTA | mixed | 稀有，8 → 0 | 初始占比 47.06%，8 → 94，非稀有 |
| DELTA | bright | 稀有，8 → 0 | 初始占比 50.00%，8 → 276，非稀有 |
| DELTA | dim | 居民于 T815 灭绝 | 初始占比 66.67%，8 → 0，非稀有 |

最终有 4 项满足稀有引入条件，均未显示从稀有增长；5 项实际不稀有，3 项居民提前灭绝。**没有一组同时满足两个方向都稀有的完整试验，本批结果尚未建立稳定共存证据。** 有效试验中的失败说明所选化能策略未能在这些光合居民环境中恢复，不能推出所有策略和环境都必然竞争排斥。

化能居民在实施反向引入时只剩 4–9 个，揭示了当前化能生态与试验建立阶段的不足。不能把引入后的两个非零计数直接称为共存，也不能把没有执行或不够稀有的方向计为有效入侵失败。

## 守恒与采样范围

模型使用抽象能量与固定组成的养分池。收支核对包含外部补给、输出、呼吸散热、初始生命注入，以及个体和环境中的库存。以下为各组运行的最大**采样绝对误差**。

| 实验组 | 能量误差 | 养分误差 | 非有限账目值 |
|---|---:|---:|---:|
| v5 四种子长跑 | `3.24e-5` 以内 | `1.74e-7` 以内 | 0 |
| v6 四种子长跑 | `3.91e-5` 以内 | `1.60e-7` 以内 | 0 |
| 群落生活史 60 次 | `7.38e-7` 以内 | `1.99e-9` 以内 | 0 |
| 入侵 12 个方向 | `4.09e-6` 以内 | `8.81e-9` 以内 | 0 |

长跑每 120 时步采样，另外保留终点或停止点；每个完整 T12000 世界有 101 个审计采样。入侵阶段在引入前后均检查账目。采样没有证明中间每一步都满足同一误差上限，数据中的人口峰值也仅是采样峰值。

维护、运动和生长账户的含义不同：增长包括转入身体的材料，繁殖包括转交给后代的储备，不能把这些账户之和都解释为生态系统损失。操作级守恒、材料不足、生长、繁殖和恢复的一致性另由自动检查覆盖。

## 复现

在 v6 仓库根目录，使用 Node.js 22：

```sh
npm ci
npm test
node scripts/calibrate-v6.mjs --out=../v6-study/current --mode=all
node scripts/colony-assay.mjs --out=../v6-study/colony-assay
```

准备独立的 v5 基线目录，并使用同一个校准脚本的明确版本分支：

```sh
git worktree add --detach ../evolution-v5 cc24ca573b3d975a575e0a8cb621f0804f8dd543
node scripts/calibrate-v6.mjs --version=5 --engine=../evolution-v5/dist/engine.js --out=../v6-study/baseline-results --mode=long
```

脚本使用 `--参数=值`。`calibrate-v6.mjs` 可选择 `--mode=long` 或 `--mode=invasion`，并设置种子、时点、建立期和引入后观察期；`colony-assay.mjs` 可设置种子、成熟规模、结构和观察长度。输出目录包含参数元数据、JSON／JSONL 结果及简要轨迹。缩短试跑示例：

```sh
node scripts/calibrate-v6.mjs --mode=long --seeds=ORIGIN-042 --horizons=600,1200 --out=../v6-study/short
node scripts/colony-assay.mjs --seeds=ORIGIN-042 --maturity=2,4 --conditions=mixed --steps=600 --out=../v6-study/colony-short
```

v5 不具备 v6 的个体摄入诊断和细胞数量状态，脚本对这些字段明确标为不适用。旧版存档仍应在对应版本打开。

## 解释局限与下一轮优先级

本轮只覆盖四个长跑种子和两个固定策略试验种子，没有现实生态参数拟合，也没有统计意义上的普遍概率估计。v5 与 v6 同时改变了多项机制、基因长度、初始基因抽样和后续随机轨迹；相同种子不能把结果差异归因于其中单一机制。

形态约束还有明显校准信号：ORIGIN 的 T12000 轴向延伸和厚度均值分别约 0.960、0.980，接近参数上界；DELTA 厚度均值约 0.938。大单体可能从接触面积获得较强收益。结构组合数量增加、体型变大和组织复杂化必须分开评价。

后续按以下顺序继续：

1. **先检查化能居民能否建立。** 分别测量热泉补给、可接触资源、迁移和维持成本，确认化能克隆在匹配环境中能维持多代。将“居民未建立”和“入侵失败”分开，并根据实际居民规模设计满足稀有条件的引入；不通过补种或保留标签维持结果。
2. **校准体型、接触面积与成本。** 用固定遗传背景比较不同身体尺寸和成熟规模，检验资源格边界、摄取能力、材料、维护及捕食关系的相互作用。检查接近形态参数上界的趋势，分别验证复杂结构能否产生、完成生活史、留下后代和扩散。
3. **再检验异质资源是否支持共存。** 在明确的资源分配权衡下，比较空间异质和均匀供给，完成双向稀有引入及更长、多种子的后续观察。以真实增长率、资源反馈和亲缘记录判断策略能否维持，允许部分组合失败；标签数量不作为成功目标。
