# v5 验证说明

记录日期：2026-09-29。这里检验人工生命模型的实现一致性、资源账、遗传追溯与固定条件下的行为，尚未进行现实生态数据校准、正式学习效果研究或无限开放演化验证。

## 方法

使用 `ORIGIN-042`、`DELTA-103`、`EDEN-221`、`STUDY-004` 四个固定种子。每轮初始化四个独立起源体系、每体系 26 个复制者，出生突变率 0.09，在默认、完全黑暗、5°C、富资源四种条件下最多运行 6,000 时步。完全灭绝或达到 2,200 个体容量会提前结束。

最终矩阵为 16 轮。每次出生核对亲本与后代的有机能量总和；每步核对累计资源账；每 60 步采样资源，每 600 步记录统计，并在终点逐出生核对遗传与亲缘证据。此前版本的实验不并入以下结果。

## 最终结果

| 条件 | 存续至 T6000 | 容量截断 | 终点个体数 | 历史分群数 | 跨标签出生合计 |
|---|---:|---:|---:|---:|---:|
| 默认 | 4/4 | 0/4 | 344–527 | 4–6 | 29 |
| 完全黑暗 | 0/4 | 0/4 | 0 | 4 | 0 |
| 5°C | 4/4 | 0/4 | 150–563 | 4–6 | 29 |
| 光照 1.5×、资源补给 2× | 4/4 | 0/4 | 1,344–1,857 | 11–18 | 1,214 |

完全黑暗各轮于 T623–T955 灭绝。该结果取决于当前初始复制者、供应和代谢尺度，不说明真实化能生态不能存在。登记标签不等同完整生物物种，跨标签出生指具有不同分类标签的兼容个体成功繁殖。

## 守恒、证据与续跑

- 共审计 69,623 次出生，其中 48,878 次双亲交叉，1,272 次跨标签出生。
- 未发现出生净制造有机能量。全程累计能量误差最大约 `7.12e-6`，抽象营养误差最大约 `1.06e-7`；未出现非有限账目值。
- 资源采样最小值约为 `-5.55e-17`，属于浮点计算余差。
- 未发现缺失亲本、缺失亲子链接、活个体缺失档案、遗传前后值或来源错误，以及没有亲本来源或新增记录的结构。
- 16/16 轮通过保存恢复及续跑一致性检查。

72 项自动检查涵盖遗传、资源、器官连接、形态、关系布局和观察功能。测试通过说明所检查的行为符合当前实现约定，不能替代生物学有效性评价。

## 因果隔离检查

| 只改变的条件 | 观察窗口 | 结果 |
|---|---:|---|
| 开启／关闭群体分类 | T6500 | 登记标签数不同；个体、资源、能量和三个随机流一致。 |
| 初始体色与斑纹 | T2500 | 排除外观数值后，运动、生存、能量与亲缘轨迹一致。 |
| 翻转初始中性标记 | T2500 | 排除标记值后，生态与随机状态一致。 |
| 出生突变率 0／0.3 | T3600 | 人口轨迹不同；外部自然事件与环境随机状态一致。 |

最后一项只检验生物与环境随机流分离，不能独自解释人口差异的完整原因。

## 尚未得到的结果

默认条件的四个终点均由单体构成。低温与富资源条件各有一个终点保留一个群落个体，最终均未自然维持两侧或辐射体制。短暂出生复杂结构、稳定保持该结构、形成完整多细胞生活史，是不同的结果。独立组合实验台中的身体不能用作自然演化证据。

四个种子不足以估计自然界的概率。结构总数和分群数仅是描述量，不作为成功评分。模型目录、结构依赖、互斥与删除规则都会影响变异供给；中性标记同时受突变与家系过程影响。

完整证据档案会增长：默认 T6000 未压缩 JSON 约 9–14 MB，富资源约 54–72 MB。浏览器中的多个对照分支会进一步占用内存。达到计算容量是明确的停止条件，不能称为生态平衡。

## 复现

在仓库根目录使用 Node.js 22：

```sh
npm ci
npm test
node scripts/v5-benchmark.js --horizon=6000 --output=./results/v5
```

脚本输出各轮汇总、时间序列、资源与遗传审计，以及参数元数据。参数使用 `--参数=值` 形式；可通过 `--seeds`、`--conditions` 和 `--horizon` 缩小观察范围。

```sh
node scripts/v5-benchmark.js --seeds=ORIGIN-042 --conditions=default --horizon=600 --output=./results/short
```

更改机制或随机数调用后，即使种子名称相同，轨迹也可能变化。跨版本的单个差异不能视为只改变一个因素的配对实验。
