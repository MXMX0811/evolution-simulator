# 源海 ORIGIN v5 · 模型说明

一个持续演进的中文人工生命生态沙盒。资源、摄食、繁殖、遗传和群体分化发生在同一个世界中；观察工具始终可用，没有课程、必做任务或器官升级目标。

## 运行

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。三维标本需要 WebGL。`dist/` 中的网页包含本地模型依赖和对照计算程序，可以直接部署到静态托管服务。

## 从一个生命进入世界

- **生态现场**：点击真实个体固定追踪，其 ID 在地图中标记。自然事件、资源和生命持续运行；打开说明或观察窗口不会自动暂停。
- **生命档案**：查看同一个体的出生身体、功能与成本、亲本、直接后代、能量账、位点来源与具体变异。死亡后的记录仍保留。
- **身体比较**：亲本和后代使用固定相机与光照；等大观察适合看结构，同一比例用于看体型。身体、推进、保护按钮定位相应器官区域。
- **种群分支**：实线表示登记的分支历史，金色虚线表示与所选分群发生过的实际交叉。可进入对应出生个体继续追踪。分类标签不是完整生物物种的证明。
- **生态网络**：食物／能源流向实际摄入的种群，近期量采用600时步指数尺度衰减；同时显示混合营养、环境库存和总账。
- **形态图鉴**：真实世界标本与独立的组合实验台分别展示。72项结构与8个形态参数组成有限的发育空间。
- **观测记录**：关键事件完整保存。可保存会话快照，并在独立分支运行三次配对对照；原世界保留自己的历史。

## 本轮机制修正

### 分类与生物过程分离

交配由独立起源体系、繁殖方式、可遗传识别信号与匹配范围，以及成熟、能量和接触条件决定。社交协作用另一组识别信号；摄食依据能力、体型、饥饿、防御和处理代价，可发生同类相食。改名、重新编号或关闭分类都不会改变生态轨迹。

创建世界时可选择有性、无性或兼性繁殖。后代继承繁殖方式；当前不模拟繁殖方式本身的随机转变。有性个体无兼容配偶时本次繁殖失败，兼性个体可以单亲复制。识别模型表示简化的交配前屏障，不含杂交后代不育。

分群登记使用空间/遗传结构、持续观察及真实新生后代证据。每144时步观察，候选与其余群体各至少8个体，均值遗传距离至少0.10；至少3次观测、288时步、4个存活新生个体和2个亲本。保留原有0.14距离作为观察聚类条件，它不再作为通用交配门槛。不同登记标签仍可恢复交流，成功交叉单独记录。未相遇不能证明隔离，无性分群也不声称交配隔离。

### 可追溯遗传

生态和形态参数分别单点交叉，共有结构保留；非共有的依赖模块各以50%概率传递。参数变化、结构获得/丢失、互斥处理和依赖连带删除分别留档。结构获得与丢失使用相同的尝试率；目录可达性和依赖规则仍会造成偏置，不能把结构数增长全归因于选择。

每次成功出生保存父母、位点来源、变异前后值、出生位置、繁殖方式和材料投入。死亡、直接后代和累计能量记录保留。失败尝试不产生出生档案。

增加一个二等位中性标记，独立继承并按突变率翻转，不参与任何功能、社交、择偶或分类。自然世界中的频率变化可能来自突变、抽样及家系变化，不能直接等同纯漂变实验。

### 身体与生态共用描述

轴长、厚度、附肢尺度和重复数驱动模型及功能代理。推进结构面积、保护厚度、外置材料同时进入出生质量、维护、运动和防御计算；体色、斑纹保持生态中性。器官使用体表锚点、根部套接及随动分组。

细胞膜和色纹、鳍条、翼根、甲片厚度与侧壁、关节、软硬材质已精修。固定档案呈现出生结构，图鉴中的活体示意动作随世界时步推进。当前未模拟真实流体、组织生长或完整碰撞。

### 资源与记录

光合/化能合成受能源与养分共同限制，摄食转移能量，未同化部分和死亡进入残骸，消耗散热并释放养分。出生材料和储备由亲代支付。所有有机物统一抽象养分比例0.035；背景生产与分解仍是资源方程。

生物、环境、中性标记分别使用随机流，均进入v5存档。世界快照可精确续跑；旧版实验应在对应原版本打开。关键事件档案完整保留，界面最近消息和历史曲线是有限窗口。

## 对照的解释

从同一快照生成两条分支，只改变一个环境条件，配对内共享初始生物随机状态及外部环境随机路径。三次重复改变生物与中性标记随机种子；生态分歧后随机数的消费顺序可以不同，不能声称每次遭遇完全相同。

每次推进600时步。触及计算容量的提前终止分支不进入完整观察窗口的均值；界面显示实际时长，导出全部原始结果与起始快照。三次最小/最大范围不是置信区间，也不能推广为普遍生物规律。

## 验证与当前边界

最终4种子×4条件、最多T6000：默认4/4存续（344–527），5°C 4/4（150–563），富资源4/4（1344–1857），完全黑暗4/4灭绝。最终矩阵无计算容量截断。69,623次出生未发现净造能、遗传来源错误或亲缘档案缺失；16/16保存恢复一致。

分类开关、只改色纹、翻转中性标记均不改变对应生态轨迹；改变生物变异过程不影响外部随机事件。这些检验说明实现一致性，不是现实数据校准。

默认终点仍以单体为主，未自然维持复杂两侧/辐射体制。组合实验台不能替代自然演化证据。后续应补群体成员关系、群体繁殖、实际合作与生产/分解者生活史，不能靠复杂度奖励制造结果。

个体容量2200，达到时明确暂停；最多登记40个历史分群。档案会随历史增长：默认T6000约9–14MB，富资源约54–72MB；导入上限128MB。内存与复制快照成本随历史增加，目前不保证无限运行。生命起源是复制者初始化，氧气是简化反馈，时步不是地质年代。

## 开发与复现

```sh
npm test
node scripts/v5-benchmark.js --horizon=6000 --output=./results/v5
```

模块：`heredity` 遗传与识别；`engine/ecology` 个体过程和资源；`development/anatomy/morphology` 身体描述与模型；`observation-view` 生命证据；`comparison/comparison-worker` 独立对照；`graphs/views/ecology-view/renderer/app` 呈现与交互。

Three.js 0.180.0、Dagre 3.1.1 随 dist/vendor 分发。无新增运行依赖。离线打包脚本 `scripts/build-offline.py 输出路径 esbuild可执行路径` 使用已有esbuild，将对照程序内嵌为独立worker。脚本不改变模块版代码。

主要依据：

- [SLiM](https://messerlab.org/slim/)：个体遗传与明确的繁殖过程。
- [Westram等，2022](https://research-explorer.ista.ac.at/download/12264/12448/2022_JourEvoBiology_Westram.pdf)：生殖隔离与基因交流的语境。
- [Sims，1994](https://www.karlsims.com/papers/siggraph94.pdf)：遗传布局与父部件表面连接。
- [Dingle等，2024](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011893)：形态变异供给偏差。
- [Thrive Auto-Evo](https://github.com/Revolutionary-Games/Thrive/blob/master/doc/auto_evo.md)：资源生态位表达；本项目不采用其定向候选生成。
- [ODD](https://www.jasss.org/23/2/7.html)：模型说明与复现边界。
- [OneZoom](https://www.onezoom.org/introduction.html)：关系图聚焦与按需展开。

实验范围、方法与结果见 [验证说明](validation.md)。具体数值是本模型的抽象常数，不能解释成论文校准参数。
