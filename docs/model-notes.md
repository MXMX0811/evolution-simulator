# 源海 ORIGIN v6 · 模型说明

源海是一个持续演进的人工生命生态系统。生命在有限资源中摄食、生长、繁殖和死亡；可遗传差异通过出生传递，改变个体能够利用的资源、身体形态及生存代价。玩家可以改变环境、追踪家系、比较分支历史，世界不设指定的终点形态。

本文说明当前实现的过程与假设。参数是模型中的抽象常数，时步不对应真实年代，三维身体也不是生物解剖复原。当前版本的实验范围、原始结果和复现方法集中在[验证说明](validation.md)。

## 运行与观察

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。三维标本需要 WebGL。`dist/` 包含本地模型依赖及独立对照程序，可直接部署到静态托管服务。

| 入口 | 能观察或进行的操作 |
|---|---|
| 生态现场 | 追踪一个真实个体，观察空间分布、资源与数量曲线；调整环境或施加事件。 |
| 生态网络 | 查看食物与能源的实际转移、环境库存、营养再循环及收支误差。 |
| 进化图谱 | 查看可表达结构的依赖和互斥条件。这是有限的构建规则，不是真实世界谱系。 |
| 种群分支 | 查看实际登记的分化历史及跨标签出生，沿后代进入生命档案。 |
| 生命档案 | 查看出生身体、亲本、后代、遗传来源、累计摄入、生长支出与群落生活史。 |
| 形态图鉴 | 观察世界代表个体的实际生长状态；在独立组合台探索相容的结构与比例。 |
| 观测记录 | 同时查看现存多样性、摄食方式、形态组合与累计传承记录；保存快照后运行环境对照。 |

观察页面与世界共享同一时间。打开说明或标本不会自动暂停，暂停和速度始终由玩家控制。

## 个体、遗传与身体

一个模拟个体包含起源身份、亲缘关系、14 个生态参数、8 个连续形态参数、结构蓝图、表达结构、繁殖识别参数、能量储备和身体材料。携带群落结构时，一个个体代表相连的同基因细胞单元共同构成的群体。

14 个生态参数覆盖光能、化能、捕食、运动、防御、协作、适温、耐受、繁殖、感知、陆生、行为可塑性，以及新增的浮游物和腐屑摄食投入。它们是归一化的遗传参数，不代表具体 DNA 序列。8 个形态参数控制轴向延伸、厚度、附肢伸长、结构重复、分枝、弯曲、体色和斑纹。

### 蓝图与表达分开记录

`structureGenes` 表示可遗传的结构蓝图，`traits` 表示出生时实际表达的结构。蓝图可以存在，而构建所需的前置结构暂时缺失。这样的蓝图继续遗传；前置恢复后，后代可能再次表达相应结构。

生态和形态参数分别单点交叉。双亲共有的结构蓝图保留，非共有的相连依赖模块各以 50% 概率传递；互斥的主轴蓝图随机保留一方。一次结构丢失尝试只删除一个蓝图，缺少前置不会永久连带删除所有下游蓝图。结构获得仍受参数阈值、前置结构、互斥及科幻设置约束。相同的获得和丢失尝试率，不能保证对复杂度无偏：目录、可达性和实际遗传抽样仍会影响结果。

每次成功出生保存亲本、位点来源、数值变化、蓝图来源、表达状态和变更原因。结构证据区分“已表达”“潜伏蓝图”和“蓝图丢失”。“出生时潜伏”是出生状态的累计计数；一个潜伏蓝图连续传递几代，可以出现几次潜伏出生，并不表示几次新的突变或失活。

失败的繁殖尝试不产生出生档案。死亡记录、直接后代和累计能量记录继续保存，因此可以区分出现过一种结构、携带者曾繁殖，以及该结构是否真正传给后代。

另有一个二等位中性标记，使用独立随机流继承和翻转。它不参与功能、择偶、社交或分类；自然世界中的频率变化仍同时受到突变、家系和抽样的影响。

## 不同摄食方式共享有限投入

光能合成、化能合成、捕食、浮游物摄食、腐屑摄食共享一个代谢投入预算。各通路的有效投入为：

```text
通路投入 = 该通路遗传参数² / max(1, 各通路遗传参数²之和)
```

总投入不超过 1。预算饱和后，提高一个通路会挤占其他通路；未饱和时，降低全部参数会同时降低摄取能力与投入成本。通路结构进一步改变相应效率，同时承担维护负担。捕食还受接触、体型、防御、识别关系和处理时间限制。

空间摄取把身体总摄取能力按身体覆盖的邻近栖息格分摊，逐格受剩余资源和养分限制并扣减库存。覆盖更多区域不等于在每个区域重复获得一份完整能力。身体变大可以接触不同位置的资源，但也增加材料、维护和移动负担。

背景光照、热泉、地形、温度、邻域交换和局部耗竭使不同位置拥有不同机会。不同策略能否长期共存，需要通过运行结果与对照实验判断；增加可用通路本身不证明已经形成稳定生态位。

没有按结构数量、复杂程度、阶段或稀有性发放的额外奖励，也没有预定某个起源最终走向捕食、光合或复杂身体。选择来自实际能量获取、生存及留下后代的差异。

## 群落的成长、成熟与释放

携带群落结构的个体从一个单元开始。储备足够时，克隆单元增长，已有身体材料随之增加；达到遗传参数决定的成熟规模后才能繁殖。成熟群体释放一个单元的繁殖体，失去的身体部分需要重新生长。

这里的细胞单元是抽象生物量单位，不对应真实细胞数，也没有模拟每个细胞的独立基因组、胞内代谢或位置动力学。同一群体共享遗传状态与储备。

生长和繁殖的账目分别记录：

- **生长投入**：从储备扣除，分为新增身体材料与生长耗散。
- **繁殖投入**：本次从亲本储备扣除，用于子代储备、新增材料及生殖耗散。
- **已有材料转交**：从亲本身体扣除，直接成为子代身体的一部分；记录在子代生活史的“亲本转入材料”，不再次计入亲本储备支出。

子代身体比转交部分更大时，差额由繁殖储备支付；转交材料超过所需时，余量按模型的耗散过程归还养分。生活史保存单元峰值、生长分裂、繁殖体释放、首次成熟及亲本材料来源。

群体大小同时影响摄取面积、移动速度、体型相关捕食和维护。组织分工通过改善群体长大后的资源输运提供功能收益，并持续支付成本；它不是附近同类数量带来的免费防御加成。实际群体成长、单元成熟阈值及组织输运指数均是明确的模型近似。

## 身体、功能与显示

身体的材料、表面积、推进和保护使用共同的发育描述。轴长、厚度、附肢尺度和重复数影响几何形态与相应功能代理；总细胞单元数改变群体体量。体色和斑纹保持生态中性。

72 项可组合结构构成有限的形态空间。模型使用身体表面连接位置、根部连接及随动分组组装器官，避免把相互独立的部位随意悬放。结构存在并不保证它在当前环境下有效：保护需要遭遇捕食，摄食器官需要相应资源，较大的身体也可能因成本而消失。

不同观察入口对应不同时间和对象：

| 标本 | 数据含义 |
|---|---|
| 世界代表个体 | 来自当前登记分群中的真实代表，显示观测到的细胞单元数与生长状态。 |
| 个体档案与亲子比较 | 重建出生身体，保持相机与光照一致；群体之后的生长另见生活史。 |
| 分叉前祖先快照 | 保留当次分群观测的代表形态，不是由后代倒推的假想祖先。 |
| 组合实验台 | 在构建规则内探索的独立成熟形态示意，没有自动加入世界，也不是自然演化证据。 |

等大显示用于比较结构；同一比例显示用于比较身体尺度。当前不计算真实流体力学、完整碰撞、细胞重排或真实组织发育过程。

## 分群标签与繁殖过程

交配取决于独立起源体系、繁殖方式、可遗传识别信号与匹配范围，以及成熟、能量和接触。独立起源体系不能互相繁殖。社交协作使用另一组识别信号；捕食可发生于同源个体之间。分类标签不参与这些判断，跨登记分支仍可能发生真实交叉。

初始繁殖方式可选有性、无性或兼性，后代继承该方式，当前不随机改变方式。有性个体缺少兼容配偶时不能完成此次繁殖，兼性个体可以单亲复制。识别条件模拟简化的交配前屏障，不包含杂交后代不育。

分群登记结合空间及遗传结构、持续观测和真实新生后代：每 144 时步检查，候选与其余群体各至少 8 个体，均值遗传距离至少 0.10；候选至少持续 3 次观测、288 时步，并有 4 个存活新生个体和 2 个亲本。观察聚类的 0.14 距离不是通用交配门槛。这些阈值是记录规则，不能解释成自然界统一的物种形成标准。

未相遇不能证明生殖隔离，无性分群也不声称已证明交配隔离。标签数量、独立起源数量、摄食方式与结构组合分别记录，不能互相替代。

## 资源账与时间口径

光合和化能合成同时受能源与养分限制。摄食转移已有有机能量，未同化部分和死亡进入残骸；消耗散热并释放抽象养分。光和地质补给是外部输入，边界交换明确记录流出。所有有机物使用统一养分比例 0.035，背景生产与分解仍由资源方程承担。

核对关系为：

```text
当前能量库存 = 初始库存 + 累计输入 − 累计散热 − 累计流出
当前养分库存 = 初始库存 + 累计输入 − 累计流出
```

储备、身体材料、浮游物和残骸都进入库存。生长把储备转为身体，繁殖把亲本资源转给子代；这些内部转移不能作为新的外部供能。氧气是简化反馈变量，不是完整化学或大气模型。

观察时需要区分三种口径：

| 口径 | 对应记录 |
|---|---|
| 当前时点 | 存活个体、分群和起源分布、表达结构组合、细胞单元及资源库存。 |
| 出生以来累计 | 每个个体的摄入来源、维护、生长与储备支出，以及出生、亲缘和性状传承档案。 |
| 近期衰减 | 每个活个体和食物网的摄入，按 600 时步指数尺度衰减；不是固定 600 步窗口或每步速率。 |

摄食分类依据个体实际摄入，而不是基因数值或分群名称。一个来源超过近期摄入的一半才标为主摄入，否则为混合；没有记录则标为暂无证据。食物网按登记标签汇总，还保留死亡个体留下的衰减记录，其合计可以不同于当前活个体的近期摄入之和。

观测台每推进 24 时步采样一次，并显示采样时刻。有效多样性使用 `exp(Shannon 熵)`：同等数量的类别分布越均匀，数值越接近类别总数。结构传承表分别提供表达携带、蓝图携带、成为亲本及传给子代的数量；生活史未结束的个体不可直接与已完成一生的个体作适合度排名。

## 对照、存档与验证

生物过程、外部环境和中性标记分别使用随机流，并进入 v6 存档。保存包含出生证据与世界状态，恢复时核对身份、遗传记录和资源状态。旧版实验应使用对应原版本打开；不同版本即使采用同名种子，也可能沿不同轨迹运行。

世界快照能产生独立环境对照。每对分支从相同快照和生物随机状态开始，仅改变一个环境条件；三次配对重复使用不同的生物与中性随机种子，外部环境路径在每对内保持一致。生物过程分歧后随机数消费顺序可能不同，不能声称每次遭遇完全相同。

每个对照推进 600 时步。触及容量而提前终止的分支不进入完整观察窗口均值，界面显示真实时长，导出包含全部结果和起始快照。三次最小／最大范围不是置信区间，也不能推广为普遍生物规律。

v6 的校准和验证记录见[验证说明](validation.md)。本文不将旧版的测试数量、出生审计数或存续结果当作 v6 结论。此前默认世界多样性收缩、复杂形态难以维持的结果，是本轮修正的动机；旧实验见固定版本的 [v5 验证记录](https://github.com/MXMX0811/evolution-simulator/blob/cc24ca573b3d975a575e0a8cb621f0804f8dd543/docs/validation.md)。新增机制是否改善长期共存、结构积累和群落生活史，需要各自的对照证据。

## 计算与科学边界

个体容量为 2,200，触及时明确暂停；最多登记 40 个历史分群。档案随着出生历史增长，复制快照和同时运行对照会继续占用内存。导入上限为 128 MB，不保证无限时间运行。触及容量不能当作生态平衡。

生命起点是初始化复制者，没有模拟从无生命化学到生命的过程。模型未提供完整的性别系统、杂交不育、独立可演化的背景分解者、细胞间冲突或生态复杂度无限增长。自然维持一种结构、短暂出生一种结构、在实验台生成一种结构，是不同的结果。
